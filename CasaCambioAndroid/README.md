# Casa de Cambio Android

- Package: `com.viralenunclick.cambio`
- URL: `https://cambio.viralenunclick.com`
- compileSdk / targetSdk: 36
- minSdk: 26
- versionCode: 1
- versionName: 1.0.0

La app es un contenedor Android WebView del panel de usuario alojado en el VPS.
Incluye carga de comprobantes, descarga autenticada, cookies/sesión y apertura externa
de enlaces que no pertenecen al dominio de Casa de Cambio.
